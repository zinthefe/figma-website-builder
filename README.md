# Figma Website Builder

Exact HTML/CSS recreation of the Figma design.

- Open `index.html` in a browser to preview.
- Fonts are loaded via Google Fonts (Inter).
- Coordinates are positioned to match the Figma layout.

## Assets
Place images into `assets/`:
- `avatar-1.png`
- `avatar-2.png`
- `avatar-3.png`
- `avatar-4.png`
- `product-placeholder.png`

If you already have these locally, just drag/drop them into the GitHub repo web UI under `assets/`.
